Xatolar jurnali

Siri va tez ochish

iPhone'da Команды (Shortcuts) ilovasi orqali Siri'ga buyruq qo'shasiz. Har bir havola dasturni kerakli oynada ochadi.

  1. Kerakli havolani Nusxalash tugmasi bilan oling.
  2. Команды → pastdagi + → Добавить действие → qidiruvga «URL» → «Открыть URL-адреса».
  3. Havolani qo'ying. Tepada nomini yozing, masalan «Kunni yakunla» → Готово.
  4. Endi «Привет Siri, kunni yakunla» desangiz, dastur shu oynada ochiladi.

Havola Safari'da ochiladi. Safari va bosh ekrandagi ilova ma'lumotlarini bulut (GitHub Gist) birlashtiradi — shuning uchun bulut ulangan bo'lsin.

PIN-kod

Dastur ochilganda va 2 daqiqadan ko'p boshqa ilovada bo'lsangiz PIN so'raladi. PIN faqat shu qurilmada saqlanadi.

GitHub Gist

Token faqat shu qurilmada saqlanadi. Uni hech kimga yubormang va GitHub'dagi kodga yozmang. Olish: github.com/settings/tokens/new → faqat gist belgisi → Generate token.

Kunlarni belgilash
